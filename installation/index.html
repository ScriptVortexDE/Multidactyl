    Installation

    Möglicherweise nicht mit allen Add-ons kompatibel

    Multidactyl verwendet Patches, um die Oberfläche zu übersetzen. Hast du vorher schon Plugins oder Themes installiert, die die Oberfläche verändern, kann es sein, dass einige Dateien nicht gepatcht werden können.

    Voraussetzungen

    • Pterodactyl Panel, installiert nach der offiziellen Anleitung (Release-Tarball)
    • Ubuntu 22.04/24.04 oder Debian 11/12/13
    • PHP 8.2 oder 8.3
    • Node.js ≥ 22 (wird bei Bedarf automatisch installiert)
    • Mindestens 2 GB RAM (oder entsprechend Swap) für den Build
    • Root-Rechte

    Panel per Git installiert?

    Wurde das Panel per Git statt per Release-Tarball installiert, meldet es die Version canary. Dann musst du die Version mit -v <version> angeben.

    Unterstützte Versionen

    Pterodactyl Panel Multidactyl-Patch (de)
    1.11.2 v1.11.2
    1.11.3 v1.11.3
    1.12.2 v1.12.2
    1.13.x, 1.14.x, 1.15.0 kein eigener Patch
    1.15.1 (aktuell) v1.15.1

    Nutzt du 1.13.x, 1.14.x oder 1.15.0, aktualisiere dein Panel am besten zuerst auf 1.15.1.

    Der einfache Weg

    Füge den folgenden Befehl in die Konsole deines Servers ein. Multidactyl installiert sich dann automatisch.

    curl -sSL https://raw.githubusercontent.com/ScriptVortexDE/Multidactyl/main/scripts/install.sh | sudo bash -s --

    curl -sSL https://raw.githubusercontent.com/ScriptVortexDE/Multidactyl/main/scripts/install.sh | sudo bash -s -- -d /var/www/pterodactyl -y

    curl -sSL https://raw.githubusercontent.com/ScriptVortexDE/Multidactyl/main/scripts/install.sh | sudo bash -s -- -c

    curl -sSL https://raw.githubusercontent.com/ScriptVortexDE/Multidactyl/main/scripts/install.sh | sudo bash -s -- -v 1.15.1

    Auf eigenes Risiko

    Nutze -v nur, wenn die vom Panel gemeldete Version nicht stimmt (z. B. canary). Ein Patch für eine andere Panel-Version passt meist nicht vollständig.

    Optionen

    Option Bedeutung
    -d <pfad> Pfad zum Panel (Standard: /var/www/pterodactyl)
    -L <sprache> Sprache des Patches (Standard de)
    -v <version> Patch-Version erzwingen
    -y ohne 10-Sekunden-Wartezeit starten
    -u Multidactyl deinstallieren (zurück auf Englisch), siehe Deinstallation
    -c nur prüfen, ob der Patch zum Panel passt – verändert nichts
    -s Status anzeigen: Panel-Version, Sprache, installierter Patch, Backups
    -l verfügbare Sprachen und Patches auflisten (braucht kein Panel und kein root)
    -V Version des Installers anzeigen
    -h Hilfe anzeigen

    Erst prüfen, dann installieren

    -c lädt den Patch, prüft die Signatur und testet mit git apply --check, ob er zu deinem Panel passt. Dein Panel bleibt dabei unverändert. Exit-Code 0 heißt „passt“, 2 heißt „passt nicht vollständig“ (die betroffenen Dateien werden angezeigt).

    Die Befehle für alle Optionen kannst du dir auch in der Versionsverwaltung zusammenklicken.

    Was der Installer macht

    1. Prüfungen: Root-Rechte, Panel-Pfad, Panel-Version, Distribution (Debian/Ubuntu), Node.js ≥ 22 (sonst wird Node 22 über NodeSource installiert) und Yarn.
    2. Backup nach /var/backups/multidactyl/.
    3. Wartungsmodus einschalten.
    4. Patch herunterladen, prüfen und anwenden.
    5. Sprache umstellen: Panel-Standardsprache und alle bestehenden Benutzer auf Deutsch, neue Benutzer bekommen ebenfalls Deutsch.
    6. Build der Oberfläche mit Yarn.
    7. Cache leeren und Rechte setzen, danach Wartungsmodus beenden.

    Schlägt der Build fehl, wird das Backup automatisch wiederhergestellt. Alle Ausgaben landen in /var/log/multidactyl.log (Fallback: multidactyl.debug.log im Panel-Ordner).

    Sprache pro Benutzer

    Unter Admin → Benutzer kannst du die Sprache einzelner Benutzer wieder auf Englisch stellen. Die fest eingebauten Oberflächentexte bleiben jedoch deutsch.

    Signierte Patches

    Der Installer wendet nur Patches an, deren SHA-256-Prüfsumme in der signierten Liste patches/de/SHA256SUMS steht. Die Signatur prüft er mit gpgv gegen den im Skript fest hinterlegten Schlüssel. Ist die Signatur ungültig oder wurde der Patch verändert, bricht die Installation ab, ohne etwas am Panel zu ändern.

    Fingerabdruck des Signaturschlüssels:

    DCE9 80AE 97BD A450 1FE7  D8AF 949F 1BD1 7BC5 9545

    Manuell prüfen kannst du einen Patch so (im Ordner patches/de/):

    gpg --import multidactyl-signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS && sha256sum --ignore-missing -c SHA256SUMS

    Patch-Quelle ändern

    Standardmäßig lädt der Installer Patches und Prüfsummen aus dem GitHub-Repository. Mit MULTIDACTYL_SOURCE nutzt du eine andere Quelle, z. B. einen lokalen Checkout (praktisch ohne Internet oder zum Testen eigener Patches):

    git clone https://github.com/ScriptVortexDE/Multidactyl.git /opt/multidactyl
MULTIDACTYL_SOURCE=/opt/multidactyl sudo -E bash /opt/multidactyl/scripts/install.sh -c

    Signatur und Prüfsummen werden auch dann geprüft.

    Patches manuell anwenden

    Funktioniert die automatische Installation bei dir nicht (z. B. weil deine Distribution nicht unterstützt wird), kannst du den Patch auch manuell anwenden. Im Beispiel liegt das Panel unter /var/www/pterodactyl.

    1. Lege ein Backup an und lade den Patch passend zu deiner Panel-Version herunter: 

      cd /var/www/pterodactyl
tar czf /root/panel-backup.tar.gz .
curl -fsSL https://raw.githubusercontent.com/ScriptVortexDE/Multidactyl/main/patches/de/v1.15.1.patch -o /tmp/multidactyl.patch

    2. Installiere bei Bedarf Node.js 22, Yarn und Git: 

      curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs git
npm install -g yarn

    3. Prüfe den Patch und wende ihn an: 

      git apply --check /tmp/multidactyl.patch
git apply --reject /tmp/multidactyl.patch

    4. Baue die Oberfläche neu und leere den Cache: 

      yarn install --frozen-lockfile
yarn run build:production
php artisan view:clear && php artisan config:clear
chown -R www-data:www-data /var/www/pterodactyl/*

    5. Stelle die Sprache ein: APP_LOCALE=de in der .env setzen und unter Admin → Benutzer die Sprache der Benutzer auf Deutsch stellen.

    Das war's – dein Pterodactyl Panel ist jetzt übersetzt. :)
