      Alle Optionen des Installers
      

        

          
OptionBedeutung

          
            
-d <pfad>Pfad zum Panel (Standard /var/www/pterodactyl)

            
-v <version>Patch-Version erzwingen, z. B. bei canary

            
-cNur prüfen: Signatur, Prüfsumme, git apply --check. Verändert nichts. Exit-Code 2, wenn der Patch nicht passt

            
-sStatus: Panel-Version, Sprache, installierter Patch, Backups, verfügbare Patches

            
-lVerfügbare Patches auflisten (ohne Panel, ohne root)

-yOhne Wartezeit starten

            
-VVersion des Installers anzeigen

            
-hHilfe

          
        

        
Die Optionen -c, -s, -l und -V gibt es ab Installer 2.0.0.

Was der Installer macht

      
Jeder Lauf folgt derselben Reihenfolge. Schlägt der Build fehl, wird das Backup automatisch zurückgespielt.

    

    

      

        
Installation

        
    
          
  1. Prüfungen root, Panel-Pfad, Panel-Version, Distribution, Node.js ≥ 22, Yarn
    2. 
          
  2. Patch laden und verifizieren SHA-256 gegen signierte Liste, Signatur mit gpgv
    3. 
          
  3. Backup nach /var/backups/germandactyl/
    4. 
          
  4. Wartungsmodus php artisan down
    5. 
          
  5. Patch anwenden git apply, bei Teil-Konflikten optional mit --reject
    6. 
          
  6. Build yarn install --frozen-lockfile, yarn run build:production
    7. 
          
  7. Sprache APP_LOCALE=de, Panel-Standard und Benutzer auf Deutsch
    8. 
          
  8. Abschluss Caches leeren, Rechte setzen, Queue neu starten, Wartungsmodus beenden
    9.

Signatur und Prüfsummen

      
Der Installer wendet nur Patches an, deren SHA-256-Prüfsumme in der signierten Liste steht. Die Signatur prüft er gegen den fest im Skript hinterlegten Schlüssel.

    

    

      

        
Signaturschlüssel

        
GermanDactyl Patch Signing · EdDSA · Fingerabdruck

        
2CB6 9766 DC1E 05E8 D805  D4C0 DF5A 303D 4015 76B8

        
Öffentlicher Schlüssel: patches/germandactyl-signing-key.asc

      

      

        
Manuell prüfen

        
Im Ordner patches/ eines Checkouts:

        
gpg --import germandactyl-signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS \
  && sha256sum --ignore-missing -c SHA256SUMS

        
Nur einen heruntergeladenen Patch prüfen:

        
sha256sum /tmp/germandactyl.patch

      

    

  


  
  

    

      
Fehlerbehebung

      
Die häufigsten Meldungen und was du dagegen tun kannst.

    

    
Unter … wurde kein Pterodactyl-Panel gefunden

      
Das Panel liegt nicht unter /var/www/pterodactyl. Gib den Pfad mit -d /dein/pfad an. Stimmt der Pfad, prüfe, ob config/app.php lesbar ist.

    

    
Für die Panel-Version … gibt es noch keinen GermanDactyl-Patch

      
Schau in die Versionstabelle oben. Für 1.13.x, 1.14.x und 1.15.0 aktualisierst du das Panel auf 1.15.1. Meldet das Panel canary, gib die Version mit -v an.

    

    
Der Patch passt nicht vollständig zu deinem Panel

      
Entweder ist GermanDactyl bereits installiert (dann -u und erneut installieren), oder ein Add-on hat die Dateien verändert. Mit -c siehst du die betroffenen Dateien, ohne etwas zu ändern. Bei wenigen Dateien kannst du den Patch teilweise anwenden lassen; die abgelehnten Stellen landen als .rej im Backup-Ordner.

    

    
Der Build ist fehlgeschlagen

      
Das Backup wird automatisch zurückgespielt. Häufige Ursachen: zu wenig RAM (mindestens 2 GB, sonst Swap anlegen) oder eine zu alte Node-Version (node -v muss 22 oder neuer zeigen). Details stehen in /var/log/germandactyl.log.

    

    
Nach einem Panel-Update ist alles wieder Englisch

      
Das Update überschreibt die Übersetzung. Führe GermanDactyl danach einfach erneut aus. Der Befehl „Panel-Update + GermanDactyl“ oben zeigt die komplette Reihenfolge.

    

    
Das Panel ist nur noch weiß

      
Meist bringt ein Theme oder Add-on eigene Dateien mit. Entpacke das offizielle Release-Tarball deiner Version neu (siehe Deinstallation in der Dokumentation), sichere vorher eigene Änderungen und führe GermanDactyl danach erneut aus.

    

    
Unbekannter Fehler? Eröffne ein Issue mit den letzten 50 Zeilen aus /var/log/germandactyl.log oder frag im Discord.
